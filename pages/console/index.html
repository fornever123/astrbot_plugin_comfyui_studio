    画风 LoRA

    这里只显示分类为“画风”的 LoRA。它和普通 LoRA长期启用列表分开；简称没有自定义时按画风1、画风2、画风3生成。每张卡片默认简洁显示，只展开当前点击的一张。

    自动使用方式：关闭时不自动加载；随机模式会从勾选的候选中抽取不重复的 LoRA；使用全部时加载所有勾选候选。常态打开的画风 LoRA 不占随机数量。用户明确写出画风简称或专属预设简称时，只使用命中的画风 LoRA，本次不会再随机叠加其它画风；指令或自然语言写“不用画风”可临时全部跳过。

    Krea 2 独立 LoRA

    只对 /水粉 与 LLM 的 engine=krea2 生效。它不读 Anima 的默认 LoRA，也不参与画风随机；文件名不含 krea2 的 LoRA 会在出图时被跳过，避免把别家权重塞进 Krea 的采样器。

    Qwen Image 2.1 独立 LoRA

    只对 /qwen 与 LLM 的 engine=qwen21 生效（图生图仍用「图生图」页面的独立 LoRA）。它不读 Anima 的默认 LoRA，也不参与画风随机。

    未分组 LoRA

    文件名不含 krea2、qwen、anima 任一关键词的 LoRA，没有被任何引擎认领。它们当前仍会落进 Anima 的默认列表；本页只做呈现，需要独立归属请重命名文件或到对应引擎页勾选。
